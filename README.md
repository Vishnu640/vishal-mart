# 🛒 Vishal Mart - Smart Grocery Delivery Platform

## 📌 Project Overview

Vishal Mart is a Full Stack Grocery Delivery Web Application that enables customers to browse products, add them to a shopping cart, place orders, and receive delivery within 4 hours. The application also provides an Admin Dashboard to manage products, orders, revenue, and inventory.

---

## 🚀 Features

### Customer
- User Registration & Login
- Secure Authentication
- Browse Products
- Search Products
- Category Filtering
- Shopping Cart
- Place Orders
- Order History
- Responsive Design

### Admin
- Admin Login
- Product Management
- Add, Update & Delete Products
- Order Management
- Dashboard Analytics
- Revenue Tracking
- Profit Calculation
- Customer Order Monitoring

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Vishnu640/vishal-mart.git
```

### Frontend

```bash
cd frontend
npm install
npm start
```

### Backend

```bash
cd backend
mvn spring-boot:run
```
